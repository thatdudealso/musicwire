# Techno production brief

Driving, hypnotic, minimal-to-peak-time arc. Original instrumental only.

Sources (accessed 2026-09-01):

- Songbrain, "How to Make Techno in 2026": peak-time pocket 130-135 BPM; kick is most of the perception; micro-evolution every 16-32 bars; DJ-friendly kick+hat intro; kickless breakdown; second drop adds one new layer.
- Beatportal, peak-time techno guide (Giordani / Brown / Beyer class, structure only): 126-132 BPM; kick+bass backbone; hats and rides for movement; intro / build / drop / breakdown / second drop / outro.
- TRACKSCORE.AI techno mixing guide: peak-time 128-145 BPM; intro 16-32 bars kick + perc; add one element per 8-16 bars; peak can be long; breakdowns shorter than house.
- BeatKey, "How to make techno music": change only one element at a time; kick stays constant; 4-on-the-floor with no swing for peak-hour.

This is **not** big-room EDM: no supersaw chorus hook, no 8-bar pop drop. Hypnosis through addition/subtraction.

## Instrumentation

| Part            | MusicXML / GM                                  | Role                                                |
| --------------- | ---------------------------------------------- | --------------------------------------------------- |
| Synth Bass      | GM 40 synth bass 2                             | Offbeat rumble / offbeat eighths under the kick.    |
| Synth Lead      | GM 83 calliope / stab                          | Sparse stabs. One pitch cell, not a pop hook.       |
| Synth Pad       | GM 90 warm pad                                 | Enters late as the "new layer" on drop 2.           |
| Techno Drum Kit | kick 36, snare 38, closed 42, open 46, ride 51 | Four-on-the-floor; open-hat offbeats; ride on peak. |

## Tempo, key, length

- 132 BPM, 4/4, D minor (one flat). Peak-time pocket.
- 92 bars = 167.3s. Shorter than a club 7-minute tool, long enough to hear the arc.
- Divisions=4.

## Harmony and groove

Ostinato: Dm pedal with a move to F then C every 8 bars (i - III - VII), then back. Minimal harmonic rate.

Kick every quarter. Open hat on the offbeat. Closed hats 16ths only after the first build. Clap/snare light on 2+4 from the groove section onward.

## Arrangement arc (92 bars)

1. Bars 1-16: kick only, then closed hats.
2. Bars 17-32: bass rumble enters.
3. Bars 33-48: stabs enter (main groove).
4. Bars 49-56: kickless breakdown (hats + stab).
5. Bars 57-80: second drop. Ride + pad as the new layer. Peak.
6. Bars 81-92: outro. Subtract to kick + hat, cadence on D.

## Anti-patterns

- Festival supersaw topline (lane 02).
- Dutch squeaky syncopated lead (lane 03).
- Piano chords carrying the form.
- Changing kick pattern (breaks DJ lock).
- Verse-chorus pop form.
